# robocop

Open source robotics control software for the Seeed Studio LeRobot SO-101 arm.

## Projects

### RoboCop Arm Controller
Web-based servo controller using the Web Serial API for direct browser-to-hardware communication.

Location: [robocop-arm/](robocop-arm/)

See [robocop-arm/README_ROBOCOP.md](robocop-arm/README_ROBOCOP.md) for detailed documentation.

## Quick Start

```bash
cd robocop-arm
npm install
npm run dev
```

Open Chrome or Edge browser to http://localhost:5173

## Original Command
```powershell
& "$env:USERPROFILE\.local\bin\phosphobot.exe" run
```
